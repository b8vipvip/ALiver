# 抖音直播伴侣可视互动采集诊断

ALiver 0.13.0 起，OCR 不再默认截取桌面坐标。桌面坐标截取会读取当前最上层窗口；当浏览器覆盖直播伴侣时，会把浏览器文字误判成评论。

采集顺序：

1. 通过已识别的直播伴侣 HWND 调用 `PrintWindow(PW_RENDERFULLCONTENT)` 读取目标窗口自身内容。
2. 如果窗口内容捕获不可用，仅当直播伴侣本身处于前台时，才允许屏幕坐标兜底。
3. 直播伴侣被其他窗口遮挡时拒绝桌面兜底，避免产生假互动事件。
4. 只裁剪配置中的“互动消息”相对区域并送入 RapidOCR。

控制台新增：

- 查看实际截图：显示采集器读取到的直播伴侣窗口与 OCR 裁剪图。
- 运行 UIA 探针：列出当前运行窗口公开的可访问文本和控件类型。
- 导出采集诊断包：生成 ZIP，包含截图、裁剪图、UIA 树、最近原始文本、最近事件和状态。
- 清空本地测试显示：重置 Bridge 本地计数和最近记录，不删除数据库历史。

诊断包默认保存在：

```text
bridge/logs/douyin_visible/douyin-visible-diagnostics-YYYYMMDD-HHMMSS.zip
```

完整扫描日志按天保存：

```text
bridge/logs/douyin_visible/collector-YYYYMMDD.jsonl
```

不建议扫描直播伴侣安装目录来寻找互动消息。Electron 静态资源不能可靠代表运行时账号、直播状态和动态渲染树；全文件扫描也无法直接得到当前评论。只读窗口探针和目标窗口内容捕获更稳定，并且不需要注入进程、读取 Cookie 或调用私有接口。
