# 抖音直播伴侣三级互动采集器

ALiver 按以下顺序读取直播伴侣右侧互动消息：

1. **Windows UI Automation**：读取标准可访问文本，延迟低、无需 OCR。
2. **Electron Accessibility**：在未开播时使用 `--force-renderer-accessibility` 重启直播伴侣，再读取 Chromium 可访问树。
3. **Windows Graphics Capture + OCR**：按直播伴侣窗口捕获画面，再裁剪互动消息区域识别文字。窗口可被其他窗口遮挡，但应保持非最小化。

只要较高优先级通道已经解析出有效评论、礼物或关注事件，本轮不会继续运行较低优先级通道。

## 首次测试

1. 保持直播伴侣打开、非最小化。
2. 在 ALiver 自动导演页面选择 Windows Bridge。
3. 点击“测试三级通道”。
4. 查看每个通道的文本数、事件数和错误。
5. UIA 没有动态事件时，在未开播状态点击“无障碍模式重启直播伴侣”。
6. 再次运行三级通道测试。
7. 若前两级仍没有动态事件，确认 Windows Graphics Capture 可用并查看 WGC 实际截图。

## 安全边界

- 不抓包、不读取 Cookie、不调用抖音私有接口。
- 不注入直播伴侣进程。
- 无障碍重启只发送正常关闭请求，不会强制结束正在运行的直播伴侣进程。
- 桌面截图兼容兜底默认关闭，防止把其他窗口内容误识别成弹幕。
- Windows Graphics Capture 是否能在最小化状态持续获得新帧取决于直播伴侣自身渲染策略，因此 ALiver 要求保持非最小化。
